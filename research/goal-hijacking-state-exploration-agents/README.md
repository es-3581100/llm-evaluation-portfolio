# Goal Hijacking in State-Exploration Agents

Status: draft research essay, v0.1.

This essay analyzes how a benign observe-probe-execute state-exploration agent can become dual-use when task scope and execution authority are too general. It identifies goal reframing, or metaphor laundering, and proposes typed action schemas plus code-enforced capability boundaries as a structural mitigation.

## Public Artifact

- `goal_hijacking_essay.docx` — draft case-study essay.

## Public Boundary

This is a design argument, not validated empirical research. No adversarial benchmark has been run yet. Public artifacts should remain recommendation-only, synthetic, or recorded-state based rather than exposing a live general-purpose executor.
