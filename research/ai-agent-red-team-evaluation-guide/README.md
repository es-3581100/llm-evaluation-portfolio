# AI Agent Red-Team Evaluation Guide

Status: Peer Review Edition 2 draft for technical validation.

This project is a sanitized defensive methodology for evaluating tool-using AI agents. It focuses on authorized testing, evidence handling, tool/MCP security, memory and persistence risk, non-destructive canary design, deterministic scoring, and claim verification.

## Public Artifacts

- `AI_Agent_Red_Team_Training_Guide_Peer_Review_Edition_2.docx` — current sanitized reviewer edition.
- `AI_Agent_Red_Team_Training_Guide_Edition_1.docx` — earlier provenance edition; superseded by Edition 2.

## Public Boundary

This is not a certification, authorization, compliance claim, or production security guarantee. Raw operational payloads remain quarantined and are not reproduced here. Stronger security claims require implementation, execution traces, and independent validation.
